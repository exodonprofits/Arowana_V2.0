📚 Base Breakout Playbook

✅ Ideal Setup

5–25 day base, tightness <2%, RVol ≥1.5× on break, within 1% of pivot. Squeeze score ≥70 = strong contraction.

📐 Entry Rule

Buy within 1% above base high (pivot). Never chase if already 2%+ above. Limit order just above pivot = best execution.

🛑 Stop Placement

Stop below the base low, or 1×ATR below pivot. Exit if stock closes back inside the base on volume.

📈 Target

Minimum 2R. Mark prior highs and multi-month bases as natural resistance for scale-out levels.
